# Arquivo

Clientes, processos e casos **encerrados ou inativos**. Mova para cá o que não
está mais em andamento, mantendo a mesma estrutura de pastas de origem.

Isso mantém as áreas ativas (`clientes/`, `consultivo/`) limpas, sem perder o
histórico.

```
arquivo/
└── clientes/
    └── joao-da-silva/    → estrutura idêntica à de origem
```

> Sugestão: ao arquivar, anote no `README.md` do cliente a data e o motivo do
> encerramento.
