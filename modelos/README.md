# Modelos (Templates)

Peças-padrão do escritório para **reaproveitar**. Ao usar um modelo, copie o
arquivo para a pasta do cliente/processo correspondente — **nunca edite o
modelo original diretamente**.

## Organização

- `peticoes/` — modelos de petições (inicial, contestação, recursos, etc.).
- `contratos/` — modelos de contratos (honorários, prestação de serviços, etc.).
- `procuracoes/` — modelos de procuração e substabelecimento.
- `pareceres/` — modelos de parecer e memorando jurídico.
- `notificacoes/` — modelos de notificação extrajudicial.

> Os modelos seguem a identidade visual do escritório (fonte, margens,
> cabeçalho com logo e rodapé com contatos).
