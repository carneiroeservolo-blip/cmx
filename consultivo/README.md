# Consultivo

Trabalhos jurídicos que **não** estão ligados a um processo judicial: pareceres,
contratos avulsos, análises, due diligence e consultas pontuais.

Organize por cliente ou por tema, conforme fizer mais sentido:

```
consultivo/
├── construtora-alfa-ltda/
│   ├── 2026-07-27-parecer-tributario.docx
│   └── 2026-08-01-analise-contrato-fornecedor.docx
└── consultas-avulsas/
    └── 2026-07-15-consulta-direito-consumidor.docx
```

> Se o trabalho consultivo evoluir para um processo judicial, crie a pasta do
> cliente em `clientes/` e mova/relacione os documentos.
